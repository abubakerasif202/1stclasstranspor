# Asset requirements

No source images were present when this app was created. Do not use unlicensed internet images or hotlinks.

| Asset | Path | Recommendation | Requirement |
| --- | --- | --- | --- |
| Master brand logo | `public/assets/brand/logo-primary.png` | Transparent PNG, at least 900px wide | Client-supplied, use unchanged and preserve aspect ratio |
| K200 intro cutout | `public/assets/trucks/k200/k200-intro-cutout.webp` | 2400 x 1600px, transparent or clean dark background | Licensed/client-supplied, front three-quarter crop |
| K200 hero | `public/assets/trucks/k200/k200-hero.webp` | 2560 x 1440px | Licensed/client-supplied, room for left-side copy |
| K220 feature | `public/assets/trucks/k220/k220-feature.webp` | 2560 x 1600px | Licensed/client-supplied, premium three-quarter crop |
| K220 side | `public/assets/trucks/k220/k220-side.webp` | 2400 x 1350px | Licensed/client-supplied, desktop parallax crop |
| Leadership image | `public/assets/leadership/div-sharma.webp` | 1200 x 1500px | Written permission and a professional portrait |
| Road/backgrounds | `public/assets/backgrounds/*.webp` | 2560 x 1440px | Licensed/client-supplied, dark readable compositions |

Use WebP or AVIF for photographic assets, include meaningful alternative text, reserve dimensions, and verify crops at 360px through 1920px viewports.
